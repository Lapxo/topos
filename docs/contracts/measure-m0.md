# M0 measure declarations

Profile: topos-measure-m0/1. Only the binary M0 domains actually published by @lapxo/obligations0.4.6 are represented. No wire, M/3, M/4 or protocol change. Non-M0 models, network parameters, 2e-DG, generic projections and resource budgets are refused here. Generic aggregation and projection-chain forms remain separate work.

The profile interprets declarations and compares them; it does not calculate, authenticate or certify statistical results. Every accepted numerical result remains declared-not-recomputed, certification not established, with model premises, computation and observation/calibration provenance still requiring verification. A theorem about uniqueness does not check a supplied inverse. Obligations0.4.6 publishes no public M0 inverse or K_eff interval API; this profile does not invent one. Public cofailurePairs supplies pair rates, not an interval or calibration receipt. coincidenceExcess requires truth and is not the oracle-free operation.

Numerical declarations require model id, selected object, observation design, units, all applicable parameters, binary64 tolerance and result. Joint independence is an explicit scoped model hypothesis with provenance; names, shares or pairwise correlation never establish it. Weights are uniform with declared K or finite nonnegative normalized weights; zeros do not count as active support. Normalization tolerance is explicit, without silently rescaling weights. Unknown K is allowed only as the target of the declared identification question.

Population moments select R2 and R4 under conditional iid with-replacement draws. They do not describe the full observable law, majority error or causal identification. Uniform-family identification requires externally known p in(0,1), c in(0,1], exact population expectations and unknown positive integer K. For general weights, only the compatible set defined by R2/R4 is represented; no singleton inverse. Published nonuniform collision at p=3/4, c=7/10,K_eff=147/4 versus c=4/5,K_eff=48 is preserved. R3 is redundant; separation by R6 for that pair proves no general identification theorem.

Finite outer enclosures require T jointly iid complete cells, N>=2, Dhat, epsilon, conditional-population iid member sampling and whole-cell uncertainty. Shared-member pairs are not independent observations; do not inflate T by the pair count. External p,c coverage boxes, marginal failure budgets and provenance are declared premises. Synthetic fixtures remain synthetic. A denominator approaching zero gives no finite upper bound absent an explicit known deterministic cap; null represents no certified finite upper bound. Calibration budgets must be retained in the union-bound declaration. This parser checks domains and retained conditions, not the numerical coverage inequality or the interval computation. An empty/incompatible confidence region does not unconditionally reject M0.

Weight participation names the published definition K_eff=1/sum(w_i^2) on normalized weights, with range1..active support. It is concentration, not a physical count of independent sources. The value is not recalculated by this profile. Declaration refinement for this object delegates interval inclusion to the existing Obligations continuous lattice, only at identical model, observation, units and numerical context. Other results compare only by exact canonical equality; no new estimator order or meet is invented.

unmeasured with a named reason and no number is valid. A numerical record missing a premise refuses; no automatic zero, confidence or independence is supplied. Canonical JSON keys and record fields use the existing UTF-8 order; golden vectors record exact bytes. Contract and vectors preserve the three original open cards and the empirical unmeasured state. Native vectors capture bounded observations; downstream consumers must verify their own inputs and contracts.
