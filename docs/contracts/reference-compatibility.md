# topos-reference-projection/1

A separate bounded inline preview and declared relation profile; historical references retain their exact meaning.

- #bound:1 and #topos-reference:1 bytes/constructors remain unchanged. The new wrapper never inserts syntax into either historical profile.
- Receiver declares inline UTF-8 byte limit; overflow refuses, never truncates. Inline text has an exact digest.
- Duplicate relations require explicit preserve/refuse. Relation names and target digests are declarations, not truth.
- Preview bytes never replace complete standing bytes or authenticate their origin. Full content remains needs/bytes/<blob>.
- A fragment is readable by page code; secrecy is not promised. Producers must not include secrets inline.
- Holder and viewer remain distinct locator classes; a viewer URL is not assumed to be a raw-byte endpoint. Availability, byte integrity and admitted disagreement remain different.
- The existing contextual meaning of none is retained; there is no silent new literal rule.
