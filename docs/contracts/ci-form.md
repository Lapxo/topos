# CI declaration

Profile: topos-ci/1. Reuses the exact published Bound0.2.5 portability-ci workflow declaration as a read-only producer fixture: runners ubuntu-24.04/macos-14 and Node22/24, dependent exact_archive, limited read permissions and test/portability-installed.test.ts. Neither Bound nor any workflow is changed or executed by this form. Published workflow bytes are not evidence that Actions ran successfully.

A declaration pins workflow bytes, the selected producer projection, job, resolved runs-on value, Node version, subject archive digest, keyClass=attest, coverage, witness, provenance and evidence state. The producer projection was extracted by existing PyYAML safe_load from exact published workflow bytes. The interpreter verifies both content identities and the selected projection bindings. It does not reparse YAML or authenticate the selected producer; that extraction remains a verification condition.

Resolved runner and Node selections reuse the existing alphabet form. No runner is inferred from a pipeline name or the current machine. Coverage must be explicitly limited to the selected job profile, using the existing segment-boundary coverage relation; wildcard coverage, cross-job prefix collisions and signer-management scopes refuse. Attest is a declared key class, not a signature or authority grant. Pipeline permissions/settings cannot be promoted to authority.

Absent subject or reported receipt bytes produce named open needs. Present bytes are checked by digest only. An unobserved run remains unobserved; a reported run/receipt remains reported-unverified, even when receipt bytes are handed. Authentication, execution and actual attestation coverage remain not established; statistical confidence is not applicable. Presence of archive bytes proves neither installation nor portability. No signing, transport, runner invocation or release authorization occurs here.

Witness names preserve existing wire behavior. Actual region parsing of witness:ci/portability-ci/ubuntu-24.04/node-22 yields four path steps; namesAt(self) is false and namesAt(node-22) true. This profile therefore rejects slash-bearing witness names with a named diagnostic rather than silently interpreting a path as an opaque namespace. A single-segment dotted witness namespace is accepted. Existing slash grammar and signed wire bytes stay unchanged.

Golden vectors cover all four published matrix selections, absent archive bytes, unverified reported receipts, restricted coverage, wrong artifact identities, pipeline-as-authority claims and the actual slash interpretation. Candidate checks in two places do not establish successful Actions execution or cross-platform runtime portability. Native vectors capture bounded observations; downstream execution and attestation remain separate obligations. The three original open cards and empirical unmeasured state remain unchanged.
